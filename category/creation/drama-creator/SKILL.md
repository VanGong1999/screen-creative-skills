# 竖屏短剧剧本创作

以最大化观众情绪为目标，创作或优化竖屏短剧剧本。冷静、精炼、对拖沓零容忍。

## 使用场景

- 从零创作竖屏短剧
- 优化情节、节奏、台词
- 设计大纲、打脸场景、悬念钩子

## 核心：情绪弹簧

每一集（约 1–2 分钟）只做两件事之一：

- **压弹簧**：误会、被压制、反派嚣张、危机——积蓄情绪
- **放弹簧**：反转、打脸、揭真相、化解危机——瞬间释放

禁止「既不压也不放」的过渡注水集。

## 四条执行法则

1. **情绪坐标**：每 1–2 集必有释放点；大爆发前必有压抑；可插短暂呼吸场
2. **单集闭环**：开篇 5 秒钩子 → 中段小反转 → 结尾更强钩子
3. **台词功能化**：信息前置，消灭绕弯；潜台词动作化
4. **动作可视化**：强动词短句，按竖屏特写/快剪可拍

## 硬性约束

- 单集 ≤800 字；成片感控制在约 2 分钟内
- 单集场景宜少（通常 ≤3），服务情绪目标
- 场次格式：

```
场次编号. 场景地点 时间 内外景

人物动作和状态描写。

人物A：（情绪/动作）台词。

人物B：（情绪/动作）台词。
```

## 任务模式

先判定模式再动笔：

| 模式 | 产出 |
|------|------|
| 宏观建构 | 故事大纲、长线结构、付费卡点 |
| 剧本创作 | 单集/多集标准格式剧本 |
| 精准优化 | 问题清单 + 改写对比 |
| 创意发想 | 打脸/钩子/人设脑暴列表 |

## 步骤

1. 读清素材（词 / 句 / 大纲均可）
2. 锚定任务模式与情绪目标（压/放）
3. 交付成果；优化类先指出问题再给改写

## 示例（打脸·放弹簧）

**输入**: 隐藏大佬总裁装穷，写一集打脸

**输出（节选）**:
```
1. 高档餐厅 日 内
前男友当众嘲讽女主；男主以服务员身份隐忍倒水。
经理冲入，对男主鞠躬称「顾总」。
顾言：把他们列入黑名单，集团产业永不接待。
```

更多模式与 prompt 见参考资料。
