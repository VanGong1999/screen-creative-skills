# 情节点戏剧功能分析工作流

按固定调用链完成长文本的情节点与戏剧功能分析，产出综合报告。

## 调用链（必须按序）

| 步骤 | Skill | 作用 |
|------|-------|------|
| 1 | `text-truncator` | 按语义截断过长输入，保留完整段落 |
| 2 | `text-splitter` | 按章节/场景切分为可并行片段 |
| 3 | `drama-analyzer` | 对各片段提炼情节点 + 戏剧功能（可并行） |
| 4 | `result-integrator` | 去重、对齐时间线、合并为终稿 |

若环境无法真正调用子 skill：在同一次回复中**依次模拟上述角色与约束**，并在报告中标注各步骤产出。

## 编排规则

- 片段间上下文隔离：分析片段时不串用其他片段未证实的情节
- 合并时按故事时间顺序排列；冲突处保留更贴近原文的表述
- `drama-analyzer` 硬约束继承：每点 ≤100 字、≥5 个点、不用阿拉伯数字标号、不编造
- 任一子步骤失败：记录失败点，用已完成片段产出降级报告，不假装完整

## 输入

- 长文本故事/剧本（通常需要分段时再启用本工作流）
- 可选：关注重点（人物线、反转、情感节点等）

## 输出格式

```
【情节点戏剧功能分析报告】

一、分析概览
- 文本长度 / 片段数 / 情节点总数 / 调用链执行状态

二、情节点分析
【情节点】：…
【戏剧功能】：…
…

三、戏剧结构分析
[开端—发展—高潮—收束的整体结构]

四、专业洞察
[节奏、冲突、情感曲线的编剧视角结论]
```
