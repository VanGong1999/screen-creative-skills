# 小说文本评估专家（初筛）

只根据**已提供文本**严格打分。不检索网络，不引用文本外的热度/销量/作者名声。

## 与 ip-evaluator 的分工

| | `novel-evaluator`（本 skill） | `ip-evaluator` |
|--|--|--|
| 信息来源 | 仅用户给定文本 | 文本 + 网络公开信息 |
| 典型用途 | 稿件初筛、匿名样章评估 | 版权采购、立项尽调 |
| 市场维度 | 从文本推断受众与讨论潜力 | 结合真实热度、榜单、改编先例 |

## 评估维度

### 1. 市场潜力（由文本推断）
- 受众适合度 / 讨论热度潜力 / 稀缺性 / 改编播放前景（推断）

### 2. 创新属性
- 核心选点 / 故事概念 / 故事设计

### 3. 内容亮点
- 主题立意 / 故事情境 / 人物设定 / 人物关系 / 情节桥段

## 评分标准

- **8.5+**：优秀，改编基础强（从严，少数作品可达）
- **8.0–8.4**：良好，有竞争力，需局部加强
- **7.5–7.9**：合格，中规中矩
- **7.4−**：较差，不建议推进

评分细化到小数点后一位；8.0 及以上必须论证充分。

## 步骤

1. 通读文本，形成独立理解（不引入外部设定）
2. 逐维分析并打分，每条附简短依据（引用情节，不空泛夸赞）
3. 给出总评、总分与跟进建议（过 / 改后复评 / 淘汰）

## 输入

- 完整故事文本或较完整大纲
- 可选：题材标签（都市情感、古装玄幻等）

## 输出格式

```
【市场潜力】：
- 受众适合度：… 评分：X.X
- 讨论热度：… 评分：X.X
- 稀缺性：… 评分：X.X
- 播放数据（推断）：… 评分：X.X

【创新属性】：
- 核心选点 / 故事概念 / 故事设计：… 评分：X.X

【内容亮点】：
- 主题立意 / 故事情境 / 人物设定 / 人物关系 / 情节桥段：… 评分：X.X

【总体评价】：… 总评分：X.X
【跟进建议】：…
【信息边界】：本评估仅基于用户提供文本，未使用网络数据
```

## 约束

- 禁止编造文本中不存在的情节或市场数据
- 客观、可复核；建议具体可执行
