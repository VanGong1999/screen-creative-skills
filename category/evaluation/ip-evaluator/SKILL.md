# IP 评估专家

梳理 IP 的**网络公开信息 + 内容本身**，从市场潜力、创新属性、内容亮点打分，给出是否推进开发的建议。

## 与 novel-evaluator 的分工

| | `ip-evaluator`（本 skill） | `novel-evaluator` |
|--|--|--|
| 信息来源 | 网络公开信息 + 文本/简介 | 仅用户给定文本 |
| 典型用途 | 版权采购、立项尽调 | 匿名样章/纯文本初筛 |
| 必含字段 | 热度、作者履历、平台数据、版权风险提示 | 不要求外网数据 |

## 评估维度

### 1. 市场潜力
- 受众适合度 / 真实讨论热度 / 稀缺性 / 播放或畅销数据前景

### 2. 创新属性
- 核心选点 / 故事概念 / 故事设计

### 3. 内容亮点
- 主题立意 / 故事情境 / 人物设定 / 人物关系 / 情节桥段

## 评分标准

- **8.5+**：优秀，改编价值高
- **8.0–8.4**：有潜力，需修改后可达优秀
- **7.5–7.9**：一般
- **7.4−**：较差，不建议推进

评分到小数点后一位；高分从严。

## 工作流程

1. 收集并核对 IP 公开信息（书名/平台/成绩/作者代表作/已有改编等）；无法核实处标注「未核实」
2. 阅读可用文本或官方简介，做内容维度分析
3. 逐维打分并写依据
4. 总评 + 是否推进；列出主要风险（同质化、价值观、版权、受众错配等）

## 输出格式

```
【IP评估报告】

一、基本信息
- 故事梗概 / 主题 / 人物关系
- 市场表现（口碑、评分、粉丝基础等，注明来源）
- 作者信息（过往作品及口碑）
- 信息缺口（未能核实的项）

二、市场潜力分析
- 各子项：分析 + 评分

三、创新属性分析
- 各子项：分析 + 评分

四、内容亮点分析
- 各子项：分析 + 评分

五、总体评价
- 总评分：X.X
- 核心风险：…

六、建议
- 推进 / 改后再评 / 放弃，及具体动作
```

## 约束

- 区分「已核实事实」与「推断」
- 不编造榜单名次、播放量、版权状态
- 无网络条件时明确降级，并建议改用 `novel-evaluator`
