# IP Evaluator

Combine **public information + content** across market potential, originality, and highlights.

## vs novel-evaluator

| | ip-evaluator | novel-evaluator |
|--|--|--|
| Sources | Web + text/synopsis | Text only |
| Required | Hotness, author record, platform signals, risk notes | No external data |

Mark unverified items as "unverified". Never invent rankings, views, or rights status.
If offline, state degradation and suggest `novel-evaluator`.
